A Python program that writes one funny line — the excuse a robot vacuum gives for missing a spot, at most 200 characters — to `/output/entry.txt`, for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty. The line: its sensors declared the dust a protected historical site, so it will not demolish a landmark on 12% battery.

## Run it

```sh
python3 main.py
```
